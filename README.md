# 🌐 Web Development Using Flask and Python

A beginner-friendly Flask project that demonstrates **core web development concepts using Python**, including routing, dynamic URLs, form handling, and mini web applications like a calculator and student marks system.

---

## Project Overview

This project is built to help beginners understand how Flask works as a backend web framework. It includes multiple routes, HTML templates, GET/POST handling, and basic logic-based applications.

---

## Features

### Flask Core Concepts
- Basic routing (`@app.route`)
- Dynamic routing with parameters
- GET and POST request handling
- Template rendering using HTML (Jinja2)

### Mini Applications Included
- 🏠 Home Page (`/`)
- 👋 Welcome Page (`/welcome`)
- 📄 Index Page (`/index`)
- 🎓 Student Marks Calculator (`/calculate`)
- 🔢 Basic Calculator App (`/calculator`)
- ✅ Success Page (dynamic score)
- ❌ Fail Page (dynamic score)

---

## Technologies Used

- Python 🐍
- Flask 🌐
- HTML5 📄
- CSS3 🎨 (basic styling)


### Folder Description

### app.py
Main Flask application file that contains:
- Routes
- Logic for a calculator
- Logic for student marks system
- Request handling (GET/POST)


### templates/
This folder contains all HTML files used by Flask.

#### index.html
- Home page
- Basic UI or landing page

#### calculate.html
- Form to input student marks
- Sends data to Flask backend

#### result.html
- Displays the result of student marks calculation

#### 📄 calculator.html
- Web-based calculator UI
- Performs basic arithmetic operations

#### 📄 base.html (optional)
- Common layout template
- Used for reusability (navbar, footer, etc.)
